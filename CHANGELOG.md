# Changelog

## 1.1.0

- Adds support for Zotero 10.0.x. Zotero 9 is no longer supported; Zotero 9
  users stay on version 1.0.0.
- Feeds without a saved sort now open sorted by date, newest first. Zotero 10
  would otherwise sort them by title.
- A sort chosen by clicking a column heading is now always saved.

## 1.0.0

- Initial release for Zotero 9.0.x.
